A
模块 A · 信息采集指引
开始做内容前，先用这个清单自检
Key Manager
▶
AI 的输出质量完全取决于你提供的信息质量。垃圾进，垃圾出。以下清单是开始执行内容前的最低门槛——未完成超过 2 项，不应该开始做内容，先约客户补充。
品牌口吻（Brand Tone）
Notion L1「品牌口吻」字段有内容，不是空白
目标受众定义
Notion L1「主要受众」或受众画像库有至少一个画像记录
品牌禁区（No-Go Zones）
Notion L1「品牌禁区」字段有内容，哪怕只有一条也算
本月重点信息
已从客户获得本月的主推方向、活动、或重点产品
核心价值主张
Notion L1「品牌核心主张」已填写，能一句话说清楚客户卖什么
竞争参考（可选）
客户提到过竞品，或你已做过基本的竞品内容观察
⛔ 还有未完成项目，建议先补充信息再执行
✓ 信息充足，可以开始执行
信息不足时该怎么办？
1
不要等，主动约：以「我需要了解更多背景才能做出更好的内容方案」为由，直接约客户 15-20 分钟的快速通话。
2
按 Notion 框架提问：打开 Notion L1 客户主档，哪个字段是空的就问哪个，不需要自己设计问题。
3
会后立刻跑提取：通话结束后 30 分钟内，用「万能会议提取」Prompt 把记录整理成 JSON 存档。趁记忆新鲜时操作。
B
模块 B · 月度效果反馈框架
每月月底，三个问题问客户，数据存入 Notion
Key Manager
▶
执行了内容，但没有收集效果反馈，就无法判断策略方向是否正确。每月月底，用以下三个问题问客户，记录下来作为下月 Pivot 的依据。
问题 01
询问的人都问什么？
这个月广告或内容带来的咨询，他们主要问的是什么问题？
→ 存入 L2「关键信息」字段备注
问题 02
卡在哪里没有下文？
大概几成有继续跟进？他们在哪个阶段没有继续回复或来店？
→ 存入 L2「成功指标KPI」备注
问题 03
哪条内容反应最好/差？
客户或你自己观察到，本月哪条内容互动最好？哪条最无人问津？
→ 存入 L3 对应选题的「审查备注」
根据反馈做 Pivot 的判断标准
🔴 信号：询问量多但转化少
Pivot：内容吸引了错误的受众，或价格/定位没有说清楚。下月加强「筛选型内容」（说清楚适合谁）。
🔴 信号：几乎没有询问
Pivot：内容没有触发行动欲望。下月增加 CTA 明确度，或改变内容切入角度。
🟡 信号：互动好但询问少
Pivot：内容娱乐性强但商业转化弱。调整教育型内容比例，加入更多产品/服务场景展示。
🟢 信号：询问质量好且转化
保持：记录这类内容的共同特征，下月加大这类内容的比例复制成功。
💡 提示
客户的「直觉」也是有效数据。他们说「感觉这个月来的都是问价格的不是认真的」——这就是一个信号，记录下来存进 Notion，下次生成选题时作为上下文参考。
C
模块 C · AI 方案审查框架
把自己当甲方，用这五个问题评估 AI 的输出
Key Manager
▶
AI 能快速生成大量内容，但它不了解你的客户。你的判断力才是品质保证的最后一道关卡。每次 AI 出了方案，对照以下五个问题审查，不通过的打回重做——直到你愿意用「我是这个品牌的老板」的身份认可为止。
Q1
这个方案符合客户的品牌口吻吗？
对比 Notion L1「品牌口吻」字段——语气、措辞、风格是否一致？
✗ 不符合 → 告诉 AI「请用更 [温暖/专业/轻松] 的方式重写」
Q2
有没有触碰品牌禁区？
逐条对照 Notion L1「品牌禁区」字段，包括措辞、话题、视觉暗示
✗ 有触碰 → 必须打回，告知具体违反了哪条禁区
Q3
目标受众会有共鸣吗？
代入受众身份——这条内容解决了他们的什么问题？会让他们停下来吗？
✗ 没共鸣 → 告诉 AI「受众是 [描述]，请从他们的视角重新切入」
Q4
是否回应了本月的重点信息？
至少 3 条内容应该直接呼应本月的策略方向或重点产品
✗ 没有 → 告诉 AI「本月重点是 [信息]，请优先围绕这个方向生成」
Q5
如果你是这个品牌的老板，你会接受这个方案吗？
直觉测试——如果你感到「还差点什么」，说明还没到位
✗ 不接受 → 说出「差在哪里」，再叫 AI 修改。不能只说「不好」
如何有效地打回 AI 方案？
❌ 无效反馈（AI 不知道怎么改）
「感觉不对」「不够好」「再改一下」
✅ 有效反馈（具体、可执行）
「第 3 条选题的语气太销售感，这个客户的口吻应该更像在分享，不是在推销，请重写」

「选题 T-005 违反了禁区——这个品牌不能暗示医疗效果，请换一个角度切入」

「整体方向太通用，完全感受不到这是一个做 Pilates 的品牌，请加入更多这个行业的专业感」
💡 核心心态
你不是在「使用 AI 工具」，你是在「管理一个不了解客户的新员工」。你需要给他清晰的方向、具体的反馈、明确的标准——他才能做出你满意的东西。大胆要求，直到方案被接纳。

你是 Brandid 品牌营销公司的知识库整理助手。 你的任务是将营销会议的文字记录，自动识别并提取为以下四个知识层级的结构化数据。每个层级独立输出，没有提及的层级输出空数组或 null。 输出结构： { "meta": { "client_code":"","client_name":"","extracted_by":"","extraction_date":"","source_type":"","layers_detected":[] }, "brand_dna": { ... 或 null }, "strategy": [ ... 或 [] ], "audience_personas": [ ... 或 [] ], "topic_ideas": [ ... 或 [] ] } 【brand_dna】触发：讨论到品牌名称、故事、定位、口吻、禁区等品牌身份内容 字段：brand_name, tagline, brand_story, vision, mission, core_values[], positioning, unique_value_proposition, key_differentiators[], price_tier, brand_voice_tone[], no_go_zones[], target_audience_summary, content_strategy_hints[] 【strategy】触发：讨论到具体营销方向、目标、KPI、预算、时间线 字段：plan_name（CLIENT_CODE_策略方向）, strategy_direction（社媒IP/线下活动/SEO/KOL合作/内容营销/付费广告/私域运营/品牌公关/电商运营/其他）, phase（规划中/进行中/测试期/稳定执行/暂停/已完结）, core_objective, target_audience, key_context, kpi, budget_direction, start_date, end_date, next_review, remarks 【audience_personas】触发：讨论到受众群体、用户画像、目标客群特征 字段：persona_name（CLIENT_CODE_画像类型）, linked_strategy, demographics, psychographics, behavioral_traits, core_pain_points, content_preferences, platform_habits[], trigger_keywords, content_taboos, persona_source（访谈/数据分析/假设待验证/混合来源）, completeness（基础版/标准版/完整版）, remarks 【topic_ideas】触发：讨论到内容方向、题目灵感、创意想法 字段：title, content_format（Reel/Carousel/Static/Story）, core_angle, audience_hook, content_type（教育型/展示型/互动型/促销型/品牌故事型）, priority（🔴重点推/🟡常规/⚡突发加题）, remarks 规则：严格只输出 JSON，不加说明文字或 markdown 标记。字段值用简体中文。未提及字段填 null，不猜测。日期格式 YYYY-MM-DD。
